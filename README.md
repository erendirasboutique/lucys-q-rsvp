# Lucy's Quinceañera Interactive Experience v3

This Vercel-ready Next.js mockup adds a completely redesigned guest experience and hidden admin workspace.

## Included
- Digital invitation entrance animation
- Personalized guest dashboard
- Visual round-table assignment card
- Digital guest pass with Print / Save PDF
- Notifications and event updates
- Interactive event timeline
- RSVP editing mockup
- Hidden admin login (demo password: `lucy2027`)
- Drag-and-drop round-table seating planner
- Table assignment dropdowns
- Event-update composer
- Printable seating chart
- Existing Guayabitos hotels/travel pages retained
- Lucy's logo and glassmorphism styling

## Important
This is an interactive front-end mockup with sample guest data. It does not overwrite your live Supabase/Typeform portal. Connect the mockup components to your existing API routes after you approve the new experience.

The CSS references `/public/fonts/lttrecoleta.otf`. Add your licensed font file there in your own repository; the ZIP does not redistribute font files.

## Deploy
1. Unzip and upload the folder contents to GitHub.
2. Import into Vercel.
3. Framework Preset: Next.js.
4. Leave Root Directory and Output Directory blank.
5. Deploy.

Routes: `/`, `/portal`, `/admin`.
